# Module 4 Assignment

- **Level:** Level 3 পর্যন্ত সম্পন্ন করেছি — Dictionary, CSV এবং JSON।
- **আটকে ছিলাম:** `totals_by()` এবং loop-এর logic কোথায় ব্যবহার করতে হবে তা নিয়ে; পরে existing class function ব্যবহার করে সমাধান করেছি।
- **CSV vs JSON:** CSV থেকে পড়লে সব value text/string হিসেবে আসে, তাই `amount` যোগ করার আগে `float()` করতে হয়। JSON সংখ্যাকে number হিসেবেই সংরক্ষণ করে, তাই `grand_total` পড়ার পরও `float` থাকে।
